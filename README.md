# Website for Blockbeat 808

Source of the public website https://take4adev.github.io (GitHub Pages of
the organization `take4adev`, owned by the owner's account; public
repository `take4adev/take4adev.github.io`, because the game's repository
is private). To update the site, copy these files into that repository and
push. Contents: start page, privacy policy (German is
authoritative, English translation), imprint, `app-ads.txt` for AdMob.

`app-ads.txt` must be at the root of the developer website, and the same
website must be entered as developer website in the Play Console.

Contact data: Marino Strick, c/o address from the mail service Postflex
(tariff "Lite": one project, for imprint and privacy policy), email
take4adev@gmail.com. The owner's private address must never be published.
The privacy policy is a careful draft, not legal advice.
